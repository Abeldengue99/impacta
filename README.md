# Impacta - A Rede Social com Propósito

Bem-vindo ao repositório oficial do projeto **Impacta**, uma rede social desenvolvida para transformar o conhecimento em impacto real no mundo através da colaboração e resolução de desafios reais.

## Arquitetura do Projeto

O projeto segue uma arquitetura baseada em separação clara de responsabilidades:
- `/frontend`: Interface do utilizador (UI/UX)
- `/backend`: Lógica de negócio, API e base de dados

## Regras de Desenvolvimento

Todo o desenvolvimento deve respeitar o **Manual Oficial de Desenvolvimento - AntiGravity Global**:
1. **Design System:** Glassmorphism Apple-style, detalhes premium.
2. **Separação Rigorosa:** Frontend e Backend nunca se misturam na mesma pasta.
3. **Segurança:** Nunca comitar ficheiros `.env` reais nem chaves sensíveis.
